# 英语学习平台

一个基于Django的英语学习平台，提供单词查询、AI助手等功能。

## 功能特性

- 📚 **单词本**: 包含CET-4、CET-6等级别的英语单词
- 🔍 **智能搜索**: 支持精准匹配和模糊搜索
- 🤖 **AI助手**: 多模型竞速的智能英语学习助手
- 📢 **公告系统**: 管理员可发布学习公告
- 🎯 **多级别词汇**: 支持不同难度等级的词汇学习

## 快速开始

### 1. 启动服务器

```bash
# 使用批处理文件启动（推荐）
.\run_server.bat

# 或者手动启动
python manage.py runserver 0.0.0.0:8080
```

### 2. 访问网站
- **主页**: http://localhost:8080/
- **单词本**: http://localhost:8080/vocabulary/
- **AI助手**: http://localhost:8080/ai/
- **管理后台**: http://localhost:8080/admin/

### 3. 管理员登录
- 用户名: admin
- 密码: admin123

## AI助手功能

AI助手支持多种大模型竞速回答：
- 本地DeepSeek R1模型（需要Ollama）
- 多个免费ChatGPT API
- HuggingFace推理API

特点：
- 2分半超时机制
- 异步竞速，最快响应优先
- 支持对话历史
- 专业英语学习指导

## 翻译API配置

### 免费翻译API（默认使用，无需注册）

系统默认使用以下免费翻译API，无需任何配置，全部并行调用取最快结果：

1. **Google翻译免费API** - 最稳定，两个端点
2. **MyMemory翻译API** - 每天1000次免费
3. **Lingva翻译API** - 开源Google翻译前端，多个镜像
4. **LibreTranslate API** - 开源翻译，多个公共实例
5. **金山词霸API** - 免费词典API
6. **有道词典免费API** - 词典查询
7. **必应词典API** - 微软词典
8. **海词词典API** - 中文词典
9. **DeepL免费端点** - 高质量翻译

**特点**：
- 10个API并行竞速，取最快返回的结果
- 翻译结果缓存10分钟，避免重复请求
- 外部API单词只显示单词和翻译，不显示解释
- 异步获取，不阻塞用户操作
- 获取成功才显示单词

## 技术栈

- **后端**: Django 6.0
- **数据库**: SQLite
- **前端**: HTML + CSS + JavaScript
- **AI集成**: 多模型API竞速机制

- 本机访问: http://localhost:8080/
